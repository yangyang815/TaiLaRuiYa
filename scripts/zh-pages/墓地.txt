'''{{tr|Graveyard}}'''是一个[[{{tr|mini-biome}}]]，当玩家附近有五个{{source code ref|v=1.4.5.6|method=Terraria.SceneState.UpdateGraveyard|field=Terraria.SceneMetrics.GraveyardTileMin}}及以上的[[{{tr|Tombstones}}]]时就会出现，达到七个{{tr|Tombstones}}时完全成型。{{tr|Graveyard}}会出现一些特殊的的视觉效果，这些效果会随着{{tr|Tombstone}}的数量逐渐增强，上限为九个{{tr|Tombstones}}：颜色饱和度降低，背景中随机劈下闪电，{{tr|Ecto Mist}}在地面上积累。

当附近有至少七个{{tr|Tombstones}}时，{{tr|Graveyard biome}}将获得额外的功能性效果：[[{{tr|Day and night cycle}}|全天]]都会生成独特的{{tr|Graveyard}}[[{{tr|enemies}}]]，以及{{tr|night}}的普通{{tr|enemy}}。[[{{tr|spawn rate}}]]没有提升，但[[{{tr|towns}}]]对{{tr|enemy}}生成的抑制效果会减弱。[[{{tr|NPC}}]] 商贩会在此处售卖独特物品，地面上的[[{{tr|Ecto Mist}}]]可以使玩家获得[[{{tr|Ecto Mist}}#{{tr|Crafting}}|独特的{{tr|crafting recipes}}]]。

[[{{tr|Sunflower}}]]对{{tr|Graveyard}}的效果有反作用：每个{{tr|Sunflower}}会抵消一个{{tr|Tombstone}}的存在。{{source code ref|v=1.4.1.2|method=Terraria.SceneMetrics.ExportTileCountsToMain}}

== 备注 ==
* 所有以玩家为中心{{buff area}}的区域内的{{tr|Tombstones}}会被计入{{tr|Graveyard biome}}的形成判定中。
** 该区域内每株{{tr|Sunflower}}都会使{{tr|Graveyard biome}}多需要一个{{tr|Tombstones}}才能形成（例如，若附近有一株{{tr|Sunflower}}，则需六个{{tr|Tombstones}}才能形成该{{tr|biome}}）；此外，若该区域内存在至少五个{{tr|Tombstones}}，{{tr|Sunflower}}将不会提供[[{{tr|Happy!}}]][[{{tr|buff}}]]。
* 虽然[[{{tr|night}}]]专属的[[{{tr|enemies}}]]能在{{tr|daytime}}于{{tr|Graveyard}}中生成，但夜间的 [[{{tr|bosses}}]] 仍不能在{{tr|day}}召唤。
* {{tr|world}}中存在[[{{tr|Hardcore}}]]{{tr|characters}}时，[[{{tr|NPCs}}]] 被杀死时会掉落{{tr|Tombstones}}，允许玩家无需牺牲{{tr|character}}就能创造{{tr|Graveyard biome}}。
* 虽然 {{tr|NPCs}} 在{{tr|Graveyard}}中时会抱怨，但是这并不会影响他们的[[{{tr|happiness}}]]。由于{{tr|Graveyard}}总是与其他{{tr|biome}}共存，他们的{{tr|happiness}}会取决于当前的另一{{tr|biome}}。
** 然而，[[{{tr|Painter}}]]在{{tr|Graveyard}}中不会出售[[{{tr|Daylight}}]]、[[{{tr|First Encounter}}]]、[[{{tr|Good Morning}}]]、[[{{tr|Underground Reward}}]]、[[{{tr|Through the Window}}]]、[[{{tr|Place Above the Clouds}}]]、和[[{{tr|Sky Guardian}}]]。
* 通常，带有[[{{tr|Fighter AI}}]] 的某些{{tr|enemies}}无法开启[[{{tr|doors}}]]和[[{{tr|Tall Gate}}]]，除非是在[[{{tr|Blood Moon}}]]期间。但在{{tr|Graveyard}}中，这些{{tr|enemies}}即使不在{{tr|Blood Moon}}期间也有 {{chance|1/60}} 的几率开启{{tr|doors}}或{{tr|Tall Gate}}。{{source code ref|v=1.4.4.9|method=Terraria.NPC.AI_003_Fighters}}
* 位于{{tr|underground}}的{{tr|Graveyard}}会生成{{tr|Ecto Mist}}，但不会生成独特{{tr|enemies}}。

== 小贴士 ==
* 大量的[[{{tr|Ecto Mist}}]]会在{{tr|Graveyard biomes}}中覆盖住地面，可能会阻挡如[[{{tr|Pressure Plates}}]]之类的物品。<!--This could previously be toggled on and off with the "Blood and Gore" [[Settings|setting]], but this appears to have been patched.-->
* 大量的{{tr|enemies}}生成，包括特别强大的[[{{tr|Ghost (enemy)}}|{{tr|Ghosts}}]]，可能会使{{tr|Graveyard}}在游戏早期相当危险。玩家会希望避免让{{tr|Tombstones}}在他们的基地和[[{{tr|spawn point}}]]周围堆积。
** [[{{tr|Mediumcore}}]]{{tr|players}}来说尤其要注意这一点，因为在同一个{{tr|spawn point}}积累太多{{tr|Tombstones}}，可能会导致一种软锁死的局面，玩家很难在不受到攻击的情况下取回物品。
* {{tr|Tombstones}}需要两个相邻的空{{tr|tiles}}才能放置。通过使地面上至少每隔一个{{tr|block}}无效，就可以完全阻止它们的放置，这包括放置[[{{tr|platforms}}]]、[[{{tr|Torches}}]]、[[{{tr|furniture}}]]、或[[{{tr|saplings}}]]，用[[{{tr|hammer}}]]将这些物块变成[[{{tr|Slope}}]]，用[[{{tr|Actuator}}]]使它们无效，或者简单地把它们挖掉。
* 在诸如[[{{tr|arena}}]]等常见死亡地点放置一些[[{{tr|Sunflower}}]]可以帮助阻止{{tr|Graveyard}}形成，不需要频繁挖掉{{tr|Tombstones}}。
** 战略性地放置半径重叠的{{tr|Sunflower}}，也可以在该{{tr|biomes}}内创造出一片非{{tr|Graveyard}}区域。这在启用了[[{{tr|secret world seed}}]] [[{{tr|What a horrible night to have a curse@Seed}}]] 的世界中尤为有用，允许玩家在白天走到建筑物的外面，而不会在那里生成{{tr|Graveyard}}{{tr|enemies}}。
* 在游戏早期收集{{tr|Tombstones}}并建造{{tr|graveyard}}，可以作为一种轻松获取[[{{tr|Abigail's Flower}}]]以及从[[{{tr|Maggot Zombie}}]]处刷取[[{{tr|Maggot}}]]作为[[{{tr|bait}}]]的方法。
* [[{{tr|Hardmode}}]]下，[[{{tr|Dryad}}]]居住在{{tr|Graveyard biome}}中时会在[[{{tr|The Corruption}}|{{tr|Corrupt}}]]{{tr|world}}售卖[[{{tr|Crimson Seeds}}]]，在[[{{tr|The Crimson}}|{{tr|Crimson}}]]{{tr|world}}中售卖[[{{tr|Corrupt Seeds}}]]，这会促进[[{{tr|evil biome}}]]共存于同一世界中，而无需从其它世界带来物品。
