# 流量与收益诊断报告

> 分析时间：2026-11-11 | 数据：We 分析（2026/09/30~11/10）+ 流量主后台

## 一、数据解读：问题在"进来的少了"，不在"留不住"

| 指标 | 现状 | 判断 |
|---|---|---|
| 日访问人数 | 均值 226，峰值 ~339（10/16），近期 ~190 | 从峰值降约 40% |
| 日新增用户 | 均值 69，累计 2907，峰值 ~122，近期 ~30 | **降约 70%，降幅最大** |
| 活跃留存 | 46.15%，较 7 日前 +21% | **在上升** |
| 新增留存 | 32.65%，+9.4% | 稳中向好 |
| 新用户来源 | Top10 全部为"自然" | 无付费推广、无外部渠道 |
| 回流用户 | 0 人 | 召回渠道完全缺失 |

**关键推理**：新增降 70% > 日活降 40% > 留存在上升——说明老用户体验没有变差（留下来的人在正常用），**问题集中在拉新端**：搜一搜带来的自然流量在萎缩。而拉新流量与两个因素强相关：

1. **内容更新节奏**：搜一搜权重与小程序的内容更新、版本发布频率相关。10/16 峰值对应上一波发版/内容更新，此后**近一个月没有发版**——这两周我们做了大量改进（缓存秒开、图标修复、性能优化、图鉴广告位、虚拟支付、赞赏），全部积压在本地未发布，用户端毫无感知，搜索权重也没有新信号
2. **搜索关键词的自然波动**：单靠"泰拉瑞亚攻略"这类词的自然搜索，热度本身有起伏，缺乏新关键词（如"灾厄"）承接增量

**结论：不是推广的问题（你没投过推广，也暂时不需要投）；是发版停滞 + 召回渠道缺失 + 关键词单薄三件事叠加。**

## 二、流量主收益低的归因

收益公式 = UV × 广告展示率 × eCPM，三个因子都在低位：

1. **UV 下降是主因**：收入从峰值 ~5 元/日降到 ~1.4 元/日，降幅与 UV 降幅（~40%）吻合——流量回升收入自然回升
2. **eCPM 结构性偏低**：工具类目用户画像（年轻、停留短、付费意愿低）+ banner 广告天然 eCPM 低（激励视频通常是 banner 的 3~10 倍，但我们触发场景只有主题解锁，展示频次很少）
3. **广告位形态旧**：后台待办里的"智能广告更新提示"就是官方在推的原生模板新形态，信息流样式的 eCPM 通常高于纯 banner，更新是零成本的

## 三、行动清单（按性价比排序）

### 立即做（零成本）

1. **发版**：把积压的全部改进发布——这是拉新权重更新 + 老用户召回的唯一杠杆。发版前完成虚拟支付真单验证，一次带齐
2. **点掉流量主待办的"立即更新"**：广告位形态升级，零代码
3. **开通订阅消息召回**：在图鉴装载完成/主题解锁完成等节点请求一次性订阅授权，数据大更新时推送（"1.4.5 图鉴数据已更新"）——**这是解决"回流用户 0 人"的解药**

### 短期做（1~2 次会话）

4. **灾厄专区一期**：灾厄关键词的搜一搜流量是新增长点且竞品空窗（已有分析报告），上线后用 stats_daily 验证
5. **分享卡片优化**：图鉴条目/攻略页的分享标题带高频关键词（"泰拉瑞亚 XX 获取方式"），分享是自然新增的另一半来源
6. **专题分类浏览**（酒馆对比报告 P1）：增加"坐骑/翅膀/宠物"等入口，承接更多搜索落地页

### 结构性优化（观察数据后）

7. **激励视频场景扩展**：eCPM 是 banner 的数倍，可设计克制的激励场景（如"看视频解锁批量收藏"），但优先级排在流量回升之后
8. 付费推广（买量）：**不建议**——工具类用户 LTV 低，买量无法回本，当前阶段钱和精力花在内容上收益更高

## 四、预期

发版 + 订阅消息召回上线后，预期 2~4 周内日访问回到 250~300 区间（峰值水平的 8 成），收入随 UV 同步回到 3~5 元/日；灾厄专区上线后新增"灾厄"关键词的自然增量。真正的收益跃迁要等流量基数上一个台阶（日 UV 500+），当前阶段的正确姿势是攒内容和功能，不是抠广告收益。
