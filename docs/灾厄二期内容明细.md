## 二、二期模块明细（A/B/C/D 四个模块 + E 暂缓项）

### 模块 A：灾厄物品图鉴精选（二期主菜，一期预留项）

**目标规模：300 条精选**（一期文档预留 300~500 条的下限起做，质量优先，后续可扩到 500）。

分类与数量预估：

| 分类 | 数量 | 内容 |
|---|---|---|
| Boss 专属武器与召唤物 | ~140 | 26 Boss 掉落的专属武器、召唤物品（每 Boss 4~6 件），含世界专属对 |
| 职业核心饰品 | ~40 | 怒气/肾上腺素联动饰品、各阶段毕业饰品及关键合成中间件 |
| 关键材料与矿锭 | ~45 | 灾厄矿石与锭（残暴矿/永恒矿/圣金源等）、灾厄精华类、Boss 魂材、生命合金 |
| 灾厄药水 | ~35 | 灾厄新增药水（暴怒药水、愤怒药水、超越药水等） |
| 召唤物与实用物品 | ~40 | Boss 召唤物、杂项实用工具 |

每条字段：名称（huijiwiki 官方简中）/ 英文名 / 分类 / 稀有度 / 获取方式（掉落 Boss 与概率，或配方）/ 效果与用途 / 关联跳转（掉落 Boss、合成产物）。

页面（2 个新页面文件，动态渲染）：
- `pkg-cal/pages/calamity-item/`：列表页，分类 tab + 进度阶段筛选，卡片复用 cal-common 样式
- `pkg-cal/pages/calamity-item-detail/`：详情单页吃 id 参数，结构对齐物品详情弹窗习惯

数据文件：`pkg-cal/data/calamity-items-weapon.js`（Boss 武器）、`calamity-items-misc.js`（材料/饰品/药水/召唤物），避免单文件过大。

图标管线（复用 Boss 图标已验证的流程）：Special:FilePath 下载（**必须自定义 UA + 串行，间隔 sleep**，并发会吃 ratelimit）→ PIL quantize(256, FASTOCTREE) → PNG，命名 `cal_it_<en>.png`。预估每张 1~2KB，300 张约 300~450KB。

### 模块 B：Boss 深度图文攻略（26 篇）

一期速查卡定位「1 分钟速查」，二期补「开战前 5 分钟阅读」的深度攻略，两层互补。

每篇固定 6 段：
1. Boss 概述与阶段机制（含血量阈值转阶段）
2. 攻击方式全表（弹幕名 + 伤害 + 规避方式）
3. 场地与准备（平台层数、Buff 清单、药水）
4. 分职业武器推荐（近战/远程/魔法/召唤/盗贼各 2~3 件，链接物品图鉴条目）
5. 常见死因与对策（每个 Boss 3~5 条，来自社区高频吐槽点）
6. 战后发展（拿掉落做什么、下一站）

呈现：新增 `pkg-cal/pages/calamity-strategy/` 独立页面（数据 `calamity-strategies.js`），Boss 详情页底部加「查看完整攻略」入口按钮。纯文本 26 篇约 70~90KB。

数据源：灾厄中文维基各 Boss 页的攻击方式表（结构化程度高，适合逐条转录）。

### 模块 C：职业配装指南（5 职业）

灾厄玩家的最大搜索刚需（贴吧/B站高频「灾厄 XX 配装」）。灾厄独有第五职业盗贼，是差异化内容。

- 五职业：近战 / 远程 / 魔法 / 召唤 / 盗贼
- 每职业按进度节点分段（对齐 Wiki Class setups 页的节点划分）：肉前 4 节点、肉后 5 节点、月主后收尾
- 每节点给：盔甲 / 武器 2~3 件 / 饰品 5 件 / 药水 / 一句话要点，物品全部链接物品图鉴条目（依赖模块 A）
- 呈现：`pkg-cal/data/calamity-careers.js` + 复用现有职业养成页的排版风格，入口放专区首页与机制页

### 模块 D：机制篇扩展（4 篇 → 10 篇）

新增 6 篇（复用 calamity-guide 页与现有渲染，纯数据追加）：

1. 复仇模式详解（Boss 增强表、复仇点数机制、推荐开启时机）
2. 死亡模式（与复仇的差异、适合人群）
3. 灾厄专属事件（酸雨、忘却之地等：触发条件、敌怪、掉落）
4. 硫磺海与深渊环境（沉沦之海生态、深渊压强与呼吸、探索准备）
5. 灾厄矿石与冶炼链（8 种新矿的分布层、熔炉、成品用途）
6. 材料来源总览（「某个材料去哪刷」速查表，反向索引 Boss 掉落）

### 模块 E：明确暂缓（三期候选，维持一期边界）

- **掉落模拟器**：需全量掉落表数据化 + 概率引擎，成本约 2 会话，价值中等 → 三期
- **灾厄合成树**：需 300+ 条配方抓取与递归渲染，二期最大成本项 → 三期（等物品图鉴数据沉淀后水到渠成）
- 模组安装教程、音乐壁纸：维持不做

## 四、准确性流程（一期教训全量沿用）

1. 译名：huijiwiki 官方简中逐条核对，禁止手译；旧译名（灾厄之影/重生之龙犽戎/至尊女巫灾厄等）已有对照经验
2. 数值与概率：逐条对原文，不确定标「待核」，不硬写
3. 掉落概率：26 Boss 已全量核对（11-22），新增物品条目直接引用核对成果，不重复劳动
4. 数据带 ver 版本标记，灾厄大版本更新后走脚本重建
5. 图标：只下官方 Wiki 图标，串行 + 自定义 UA，本地一律 PNG（webp iOS 不渲染的老坑）

## 五、校验扩展（verify-data.js 第 9 节追加）

- 物品图鉴：条目总数断言、每条字段完整性、分类分布、图标文件与映射双向校验（icons 清单 ↔ assets 目录逐一比对）
- Boss 攻略：26 篇与 Boss id 一一对应断言（多一篇少一篇都 FAIL）
- 配装指南：五职业齐全 + 每职业节点数断言
- 关联跳转：物品条目里引用的 Boss id 必须存在于 calamity-bosses.js（防悬空链接）

## 七、需要拍板的 4 个点

1. **物品图鉴规模**：推荐 300 条精选起步（1.1/1.2 分批）；备选一步到位 500 条（会话 +2，首批上线更慢）
2. **Boss 深度攻略呈现**：推荐独立 calamity-strategy 页（详情页加入口按钮）；备选并入 Boss 详情页加长（页面过长，不推荐）
3. **配装指南范围**：推荐五职业全做（盗贼是灾厄差异化卖点）；备选先做召唤/盗贼/法师三热门（省 0.5 会话）
4. **掉落模拟器与灾厄合成树**：推荐三期（等物品数据沉淀）；备选二期 1.2 插入合成树（会话 +2~3）
