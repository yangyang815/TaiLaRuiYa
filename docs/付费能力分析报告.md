# 小程序付费能力全面分析报告

> 分析时间：2026-11-09 | 依据：微信官方文档 + 2026-11-04 官方公告（个人开发者虚拟支付开放）

## 一、政策核实：你说得对，个人现在能收款了

微信于 2026 年 11 月初向个人主体小程序开放**虚拟支付**，同批还开放了**赞赏**收款。核实到的关键政策：

| 项目 | 内容 |
|---|---|
| 开通条件 | ① 小程序主体为个人 ② 服务类目含「工具」③ 已完成认证和备案 |
| 卖什么 | **仅限虚拟商品/服务**：功能解锁、付费内容、打赏等；不能卖实物 |
| 限额 | 月支付限额 10 万元（所有终端合计） |
| 费率 | Android 等 1%（腾讯技术服务费）；iOS 12%（Apple 佣金） |
| 账期 | Android T+3；iOS 约 45~60 天（Apple 结算） |
| 退款 | 180 天内退款退手续费，超 180 天不退 |
| 开通流程 | mp 后台 → 支付与交易 → 虚拟支付 → 开通（约 5 分钟审核）→ 道具管理创建商品并发布 |
| iOS 补充 | 需配置小程序简称；用户需 iOS 15+、微信 8.0.68+ |

同批新政还有一条对我们有用：**"喜欢开发者"赞赏按钮，平台抽成 0**。

注意：传统微信支付（商户号，卖实物/服务类）个人主体依然不能开，那条路要注册个体工商户。虚拟支付足够覆盖我们想做的会员/解锁场景。

## 二、我们小程序的资格对照（3 个待确认项）

| 条件 | 现状 | 待办 |
|---|---|---|
| 个人主体 | 大概率是（需确认） | mp 后台 → 设置 → 基本信息确认主体类型 |
| 类目含「工具」 | 待确认 | mp 后台 → 服务类目。攻略工具一般选了"工具"或"资讯"，若只有"资讯"需增类目 |
| 认证+备案 | 待确认 | 个人小程序备案是 2023 年后要求，确认是否已完成 |

这三项都满足才能开通，缺一先补。

## 三、三条收款路径对比

| 路径 | 抽成 | 上线成本 | 风险 | 建议 |
|---|---|---|---|---|
| ① 虚拟支付：功能解锁/会员 | Android 1% / iOS 12% | 中（道具配置+云开发接入+会员体系） | 中（见第四节版权提示） | **主力，做** |
| ② 赞赏"喜欢开发者" | **0%** | 极低（后台开+一个按钮） | 几乎无 | **立刻做，白捡** |
| ③ 广告（流量主） | 平台分成 | 已在运行 | 无 | 维持现状，是新付费的收益基线 |

## 四、版权风险提示（做付费前必须想清楚的一件事）

我们的小程序内容是泰拉瑞亚（Re-Logic 的游戏）的攻略数据与图标。**"免费+广告"的攻略工具是行业惯例，版权方容忍度高；一旦建立付费墙，商业风险感知会上升**。规避原则：

- 付费权益绑定**我们自己的增值服务**（去广告、主题皮肤、专属工具、体验优化），不把"游戏数据本身"作为付费卖点
- 不宣传"付费才能看攻略"——攻略主体永远免费开放
- 会员命名避免使用游戏官方商标（比如不叫"泰拉瑞亚 VIP"，叫"酒馆通/探索者会员"之类自有命名）
- 参考先例：泰拉酒馆 APP 也是"免费查数据 + 广告"模式，未见卖数据

## 五、商品设计建议（卖什么、怎么定价）

结合我们现有的功能资产（主题商店 8 主题、图鉴、工具分包、广告位），推荐组合：

| 商品 | 定价参考 | 设计理由 |
|---|---|---|
| **去广告（永久）** | 6~12 元一次性 | 广告人均收益约 0.1~0.5 元/人/月，一次性定价远超 LTV，用户算得过来账，转化率最高的虚拟商品形态 |
| **全主题礼包** | 3~6 元一次性 | 现在解锁主题要看激励视频（免费路径保留），付费是"懒得看广告"的快捷方式，不破坏现有体验 |
| 探索者会员（可选，二期） | 6 元/月 或 30 元/年 | 权益=去广告+全主题+新工具优先体验。**不建议首发做订阅**：会员留存运营成本高，先看一次性商品的转化数据再决定 |

明确不建议卖：游戏数据查询本身、攻略内容（版权风险 + 破坏免费体验基本盘）、虚拟货币（合规复杂）。

## 六、技术实现路线（云开发方案）

好消息：官方为个人虚拟支付提供了**微信云开发快速接入**，我们正好全栈在云开发上。

1. **后台**：开通虚拟支付 → 道具管理创建商品（去广告、主题礼包）→ 记录 OfferID / 现网AppKey
2. **支付调用**：云开发环境调用虚拟支付 SDK 下单（Android/iOS 自动区分费率），客户端 `wx.requestOrderPayment` 拉起
3. **发货与权益**：支付回调云函数 → 以 **openid** 为键写入权益表（云数据库 `memberships` 集合：openid、权益项、到期时间、订单号）——无需登录注册体系，天然防篡改
4. **客户端生效**：图鉴/详情页广告组件包一层 `wx:if="{{!isPro}}"`；theme.js 主题解锁增加"会员全解锁"分支；启动时云函数查询权益缓存本地
5. **iOS/安卓差异**：同一道具两端口径一致，费率由平台处理；iOS 用户低于微信 8.0.68 需隐藏购买入口并提示

预估工作量：会员权益系统 + 支付接入 + 去广告/主题改造，约 1~2 次会话；赞赏按钮半小时。

## 七、建议行动清单（按顺序）

1. **今天可做**：mp 后台确认主体/类目/备案三项资格
2. **零风险白捡**：后台开通"喜欢开发者"赞赏 → 我来加按钮（放帮助页/关于页）
3. **收益主力**：开通虚拟支付 → 定商品（去广告 6~12 元 + 全主题礼包 3~6 元）→ 我做云开发接入与会员体系
4. **数据驱动**：上线后用 stats_daily 和支付转化数据决定是否做订阅制会员
