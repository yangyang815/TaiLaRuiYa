# 发帖选题思路库（贴吧 / TapTap / B站通用）

生成时间：2026-11-17
用法：这份是"选题源清单 + 思路框架"，不含正文。每条给了标题思路和素材位置，写的时候按上一份文案包里的格式展开即可。

---

## 一、五个选题方向（想不出写什么时，按顺序过一遍）

**A. 反常识纠错（传播力最强）**
老玩家的记忆错误或网上流传的错误说法，就是天然的传播点。素材来源：本项目 70+ 条纠错记录（星力手环、泰拉棱镜、克眼掉矿全是真实案例）。

**B. 新手刚需（搜索量最大）**
新手在搜一搜里找的东西：怎么开局、NPC 为什么不住、Boss 先打谁。素材来源：帮助页 FAQ、新手指南。

**C. 版本热点（时效性强）**
1.4.5 新内容、每次官方更新。素材来源：图鉴卷数据 diff、帮助页"版本差异"条目。

**D. 机制深挖（长尾常青）**
系统级机制讲透一篇，半年后还有人搜。素材来源：图鉴数据、Wiki 已核对内容。

**E. 工具与开发者故事（建人设、养社区）**
"我做了一个工具"本身也是内容，TapTap 对开发者宽容度高。

**F. 灾厄专区（预留，上线后启用）**
灾厄是下一个最大选题库，上线即有一批现成内容。

## 三、选题筛选三问（一条选题值不值得写）

1. **搜一搜有没有需求**：新手刚需类永远有；冷知识类看反差点强不强
2. **有没有记忆错误或争议**：有反差才有转发（A 类最强）
3. **素材是否现成**：图鉴/攻略库已有数据 = 半小时成文；要现查 Wiki = 排后

---

## 四、持续产选题的三个固定习惯

1. **每周扫一遍玩家反馈队列**：每条纠错反馈都是一个 A 类选题（星力手环就是这么来的）
2. **每次发版留 diff**：更新内容 = 更新帖 + 下周干货帖的素材
3. **评论区/群里被问两次以上的问题**：直接立为下一帖选题（说明搜一搜里也在搜这个）
