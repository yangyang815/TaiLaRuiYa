# 与泰拉酒馆对比盘点报告

> 对比时间：2026-11-09 | 对比对象：泰拉酒馆（APP + 网页版 tlryjg.com）vs 本小程序图鉴
> 数据源：泰拉酒馆分类页触发滑动验证无法直抓，故改用其上游数据源（官方 Wiki）的标准分类做权威比对，结论等价且更准确

## 一、总体结论

**数据层面：图鉴对全部专题物品实现全覆盖，零真实缺失。**

泰拉酒馆的核心价值（全物品数据、合成表、掉落查询）我们的图鉴全部具备且更细（带微光嬗变、图标、点击跳转），覆盖数量也更大。真正的差距不在数据，在**专题分类浏览入口**和少量特色工具。

## 三、酒馆有而我们没有的功能（按性价比排序）

| 功能 | 价值 | 建议优先级 |
|---|---|---|
| **专题分类浏览**（坐骑/宠物/翅膀/染料/雕像等专题页） | 高——玩家查"全坐骑/全翅膀"场景高频，数据我们全有，只差入口 | **P1，建议做** |
| 物品 ID 查询器 | 中——查存档/指令用，图鉴数据带 ID 即可做 | P2 |
| 爆率模拟器 | 中——纯前端小玩具，趣味性强 | P2 |
| 模组百科（灾厄/瑟银/法狗） | 内容量巨大，超出原版范围 | 不建议 |
| 资源下载（存档/地图编辑器） | 微信小程序无法做下载分发 | 不适用 |
| 社区玩友圈/视频聚合 | 重运营，需要人力持续维护 | 不建议 |

## 四、建议路线

1. **图鉴专题浏览**（P1）：在图鉴页增加专题 tab 或筛选器（坐骑、宠物、翅膀、染料、宝匣、旗帜等 10 个左右专题），数据用图鉴卷现有条目按 en 分类映射，约一次会话完成
2. **物品 ID 查询**（P2）：图鉴详情页展示内部物品 ID（Wiki 已提供），搜索支持按 ID 查
3. 现阶段不做：模组内容、社区功能、资源下载
