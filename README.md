# 泰拉瑞亚手册 · TERRA HANDBOOK

一个功能完整的泰拉瑞亚玩家助手微信小程序 —— 图鉴查询 / 合成树 / 职业养成 / 钓鱼助手 / Boss 攻略，一站式覆盖。

> 玩家自制学习作品，与 Re-Logic 无关。数据参考 [Terraria Wiki](https://terraria.wiki.gg)（数据口径 1.4.5，覆盖全部 44 种特殊种子）。

## ✨ 功能一览

### 📖 图鉴（840+ 条目）
- 物品 / 敌怪 / Boss / NPC / 特殊种子五大板块（633 项物品，名称对齐官方 wiki），半屏详情 + 收藏打卡
- 条目名称对照官方 wiki 译名，支持**拼音 / 首字母 / 英文 / 俗称**模糊搜索（如输入 `ny` 搜到鲶鱼）
- 「获取方式」内嵌实体超链接，点击直达关联条目，功能闭环

### ⚒ 合成速查（132 条配方）
- 输入目标物品自动展开**多层合成树**，逐层缺料标红
- 一级材料清单可勾选"已拥有"，自动盘点缺口
- 智能联想带工作台 / 分类标签，支持按物品类型与制作站筛选

### 🗺 职业养成
- 战士 / 射手 / 法师 / 召唤师四职业，各 8 阶段成长路线（可打卡追踪）
- 职业专属专题页：攻略合集 + 按阶段配装推荐 + Boss 打法汇总
- 每阶段关联该阶段的深度攻略文章

### 🎣 钓鱼助手
- 鱼种图鉴 95 项（任务鱼 / 可钓获 / 钓具 / 鱼饵 / 宝匣），按地形 / 时间 / 天气三维筛选
- 今日渔夫任务：钓取地点与条件 + 一键打卡
- 按当前现实时间推荐"现在适合钓什么"

### 🧭 更多模块
- **Boss 攻略清单**：30 个 Boss 的召唤方式 / 准备清单（可打勾）/ 战后收获
- **获取方式速查**：物品获取路径一页通
- **DPS 计算器** / **NPC 规划**（晶塔布局）/ **建造指南**（8 个建筑案例）
- **冒险成就** / **泰拉游戏成就** / **冒险等级**系统
- **全局搜索**：一次搜出图鉴条目 / 合成配方 / 攻略 / 钓鱼数据 / Boss 清单

### 💾 存档备份
- 全部进度一键导出（JSON 复制 + 二维码），新设备扫码或粘贴导入
- 每日定时自动提交备份（可选）

## 🛠 技术特点

- **原生微信小程序**，零第三方运行时依赖
- **纯 JS PNG 编码器**：像素字符画 → 调色板 PNG base64（无 Canvas、同步计算、内存缓存）
- **像素图标组件**：822 张官方精灵图 + 像素画回退，lazy-load + 加载失败自动降级
- **迷你拼音引擎**：全量条目拼音 / 首字母索引（自定义字符表，缺失字可增补）
- **自定义主题**：深色 / 浅色双主题，组件级样式隔离

## 📂 目录结构

```
├── app.js / app.json / app.wxss   # 全局配置
├── pages/            # 31 个页面（home/codex/craft/my 四 Tab + 27 子页）
├── components/       # pixel-icon 像素图标（缓存渲染）
├── custom-tab-bar/   # 自定义底部导航
├── data/             # 全量数据（items 633 / monsters / bosses / recipes / seeds / strategies ...）
├── utils/            # 逻辑层（dex 搜索 / store 存档 / png 编码 / 拼音 / 钓鱼 / 职业逻辑）
├── assets/
│   ├── sprites/      # 822 张官方精灵图
│   └── picture/      # 建筑案例场景图
└── scripts/          # 数据维护脚本（见下）
```

## 🧰 数据维护脚本

| 脚本 | 用途 |
|---|---|
| `node scripts/verify-data.js` | 数据完整性校验（提交前建议跑一次） |
| `node scripts/verify-names.js [--fix]` | 条目中文名对照官方 wiki 核对 / 自动修正 |
| `node scripts/expand-items.js` | 批量新增物品（自动从 wiki 下载精灵图并追加条目） |
| `node scripts/fix-append.js` | 幂等重建图鉴补全区块 |
| `node scripts/gen-spritemap.js` | 按精灵图目录重建 spritemap 映射 |
| `node scripts/check-pinyin.js` | 检查拼音表缺失汉字 |

## 🚀 开发

1. 克隆本仓库
2. 用**微信开发者工具**打开项目根目录（appid 需替换为自己的）
3. 编译预览即可，无需 npm install

上传前注意包体积上限 2MB（当前约 1.9MB，`scripts/` 与 `.workbuddy/` 已配置不上传）。
